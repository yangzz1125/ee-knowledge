# 前端学习笔记

> 项目背景：电磁场与波 AI 知识图谱
>
> 当前阶段：HTML/CSS 基础学习，准备进入 JavaScript。

## 一、前端的三要素

前端主要由三部分组成：

| 技术 | 作用 | 类比 |
| --- | --- | --- |
| HTML | 网页结构和内容 | 房子的结构与房间 |
| CSS | 网页样式和布局 | 墙面、颜色与装修 |
| JavaScript | 网页行为和交互 | 电灯、按钮和自动化功能 |

当前项目的前端目标是构建一个“电磁场与波 AI 知识图谱”页面，包含顶部栏、左侧章节栏、中间图谱区域、右侧知识详情和底部 AI 助手。

## 二、HTML 基础

### 2.1 HTML 文档结构

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
  <meta charset="UTF-8">
  <title>页面标题</title>
</head>
<body>
  <h1>页面内容</h1>
</body>
</html>
```

- `<!DOCTYPE html>`：声明使用 HTML5。
- `<html>`：网页根元素，所有内容都放在其中。
- `lang="zh-CN"`：说明页面主要使用简体中文。
- `<head>`：保存网页配置，通常不直接显示在页面主体中。
- `<meta charset="UTF-8">`：设置字符编码，保证中文正常显示。
- `<title>`：设置浏览器标签页标题。
- `<body>`：保存网页中真正显示给用户的内容。

### 2.2 常见 HTML 标签

```html
<h1>一级标题</h1>
<h2>二级标题</h2>
<h3>三级标题</h3>
<p>这是一个段落。</p>
<button>查看详情</button>
```

- 标题：`h1`、`h2`、`h3` 等。
- 段落：`p`。
- 按钮：`button`。
- 容器：`div`，主要用于分组和布局，本身没有特殊语义。

大多数 HTML 标签由开始标签、内容和结束标签组成：

```html
<p>这是一段文字</p>
```

### 2.3 语义化标签

常见语义化标签：

```html
<header>顶部区域</header>
<main>主要内容</main>
<aside>侧边栏</aside>
<section>内容区块</section>
<article>独立内容</article>
<footer>底部区域</footer>
```

它们和 `div` 一样可以组织页面，但名称能够表达区域含义，便于阅读、维护和后续开发。

知识图谱页面可以组织成：

```text
body
├── header       顶部栏
├── aside        左侧章节栏
├── main         主内容区
│   └── article  知识点卡片
└── footer       底部区域
```

### 2.4 HTML 标签嵌套

```html
<div class="graph-preview">
  <article class="knowledge-card">
    <h3>梯度</h3>
    <p>描述标量场变化最快方向的向量。</p>
  </article>
</div>
```

结构关系是：

```text
graph-preview
└── knowledge-card
    ├── h3
    └── p
```

HTML 的嵌套表示元素之间的父子关系，但不等于 `class` 继承关系。

### 2.5 HTML 注释

```html
<!-- 这是 HTML 注释 -->
```

多行注释：

```html
<!--
  这是一个多行注释。
  浏览器不会显示它。
-->
```

注释不会显示在网页上，主要用于解释代码、标记区域和方便后续阅读。注释中不要保存密码、密钥等敏感信息。

### 2.6 HTML 属性

```html
<button
  id="maxwell-button"
  class="knowledge-button"
  data-node-id="maxwell-equations"
  data-node-name="麦克斯韦方程组">
  麦克斯韦方程组
</button>
```

#### `id`

```html
id="maxwell-button"
```

表示元素的唯一标识。一个页面中同一个 `id` 通常只使用一次，JavaScript 可以通过它定位某个元素。

#### `class`

```html
class="knowledge-button"
```

表示元素所属的类别。多个元素可以使用同一个 `class`，方便 CSS 统一设置样式。

#### `data-*`

```html
data-node-id="maxwell-equations"
data-node-name="麦克斯韦方程组"
```

这是自定义数据属性，可以保存知识点 ID、名称、描述和公式等信息，后续可由 JavaScript 读取。

简单区别：

```text
id：通常唯一，用于定位单个元素
class：可以重复，用于表示一类元素
data-*：保存元素相关的自定义数据
```

## 三、CSS 基础

### 3.1 CSS 的作用和基本语法

CSS 用来控制颜色、字体、大小、间距、边框、圆角、页面布局和响应式效果。

基本语法：

```css
选择器 {
  属性: 属性值;
}
```

例如：

```css
body {
  background-color: #f3f8fa;
  color: #18324a;
}
```

- `body`：选择器。
- `background-color` 和 `color`：属性。
- `#f3f8fa` 和 `#18324a`：属性值。

CSS 注释使用：

```css
/* 这是 CSS 注释 */
```

### 3.2 `<style>` 标签

可以把 CSS 直接写在 HTML 文件的 `<style>` 标签中：

```html
<style>
  body {
    background-color: #f3f8fa;
  }
</style>
```

`<style>` 中的内容会被浏览器当作 CSS 解析，通常放在 `<head>` 中，让浏览器在显示页面前先读取样式。

适合场景：

- 学习和练习。
- 小型 Demo。
- 只有一个页面的简单项目。

### 3.3 外部 CSS 文件

CSS 也可以单独保存为文件：

```text
step-05-external.html
step-05-style.css
```

HTML 通过以下方式引入：

```html
<link rel="stylesheet" href="step-05-style.css">
```

- `rel="stylesheet"`：说明引入的是样式表。
- `href`：指定 CSS 文件路径。

外部 CSS 的优点：

- HTML 只负责结构，CSS 只负责样式。
- 多个页面可以复用样式。
- 文件更容易维护。

### 3.4 CSS 选择器

#### 标签选择器

```css
body {
  margin: 0;
}
```

选择所有 `body` 元素。

#### class 选择器

```css
.sidebar {
  background-color: #eef7f8;
}
```

前面的点 `.` 表示选择 `class`。

#### id 选择器

```css
#page-title {
  color: #087f8c;
}
```

前面的 `#` 表示选择 `id`。

#### 后代选择器

```css
.knowledge-card h3 {
  color: #087f8c;
}
```

表示选择 `.knowledge-card` 内部的 `h3` 元素。

#### 伪类选择器

```css
.knowledge-button:hover {
  background-color: #056d75;
}
```

`:hover` 表示鼠标悬停状态。常见伪类还有 `:active`（按下）和 `:focus`（获得焦点）。

### 3.5 CSS 继承和优先级

`class` 不会因为 HTML 嵌套而继承：

```html
<div class="graph-preview">
  <article class="knowledge-card"></article>
</div>
```

这里是两个元素分别拥有两个 `class`，不是 `knowledge-card` 继承了 `graph-preview`。

有些文字相关属性可以从父元素继承，例如：

```css
.graph-preview {
  color: blue;
  font-family: Arial;
}
```

但 `display`、`padding`、`border` 等布局和盒模型属性通常不会自动继承。

选择器优先级可以简单理解为：

```text
标签选择器 < class 选择器 < id 选择器
```

选择器越具体，优先级通常越高；优先级相同时，后写的规则通常覆盖先写的规则。

### 3.6 CSS 盒模型

每个 HTML 元素都可以看成一个盒子：

```text
content
  ↓
padding
  ↓
border
  ↓
margin
```

- `content`：元素真正的内容。
- `padding`：内容与边框之间的内部距离。
- `border`：元素边框。
- `margin`：元素与其他元素之间的外部距离。

例如：

```css
.content-area {
  margin-top: 24px;
  padding: 24px;
  border: 1px solid #dcecef;
}
```

`width` 默认只表示内容宽度。若希望宽度包含内容、内边距和边框，可以使用：

```css
box-sizing: border-box;
```

## 四、左侧栏 CSS

HTML 结构：

```html
<aside class="sidebar">
  <h2>课程章节</h2>
  <ul class="chapter-list">
    <li>矢量分析</li>
    <li>静电场</li>
    <li>恒定磁场</li>
    <li>电磁波</li>
  </ul>
</aside>
```

主要 CSS：

```css
.sidebar {
  width: 240px;
  padding: 24px;
  background-color: #eef7f8;
}

.sidebar h2 {
  margin-top: 0;
  font-size: 18px;
}

.chapter-list {
  display: flex;
  flex-direction: column;
  gap: 8px;
  padding: 0;
  margin: 0;
  list-style: none;
}
```

参数含义：

| 参数 | 作用 |
| --- | --- |
| `width` | 设置侧边栏宽度 |
| `padding` | 设置内容与边缘的内部距离 |
| `background-color` | 设置背景颜色 |
| `margin-top` | 设置标题顶部外边距 |
| `font-size` | 设置标题文字大小 |
| `display: flex` | 使用 Flex 布局 |
| `flex-direction: column` | 让章节垂直排列 |
| `gap` | 设置章节之间的间距 |
| `list-style: none` | 去掉列表项目符号 |

选中章节的样式可以写成：

```css
.chapter-item.active {
  background-color: white;
  color: #087f8c;
  font-weight: bold;
}
```

它选择同时拥有 `chapter-item` 和 `active` 两个 `class` 的元素。

## 五、Flex 布局

### 5.1 基本作用

父元素设置：

```css
.page-layout {
  display: flex;
}
```

HTML：

```html
<div class="page-layout">
  <aside class="sidebar">侧边栏</aside>
  <main class="main-content">主内容</main>
</div>
```

使用 Flex 后，侧边栏和主内容可以横向排列：

```text
侧边栏 | 主内容
```

父元素负责控制子元素的排列方式，子元素负责自己的样式。

### 5.2 常用 Flex 参数

#### `flex-direction`

```css
flex-direction: row;
```

让子元素水平排列。

```css
flex-direction: column;
```

让子元素垂直排列。

#### `justify-content`

控制主轴方向上的分布：

```css
justify-content: flex-start;    /* 靠起点 */
justify-content: center;        /* 居中 */
justify-content: flex-end;      /* 靠终点 */
justify-content: space-between; /* 两端对齐 */
```

顶部栏常用：

```css
.page-header {
  display: flex;
  justify-content: space-between;
}
```

效果是标题在左边，其他信息在右边。

#### `align-items`

```css
align-items: center;
```

控制交叉轴方向的对齐。顶部栏是横向排列时，它通常控制垂直方向的居中。

#### `gap`

```css
gap: 16px;
```

设置 Flex 子元素之间的间距，比给每个元素单独设置 `margin` 更方便。

#### `flex-wrap`

```css
.graph-preview {
  display: flex;
  flex-wrap: wrap;
}
```

空间不足时允许子元素换行。

#### `flex`

```css
.main-content {
  flex: 1;
}
```

表示主内容占据剩余空间。

```css
.knowledge-card {
  flex: 1 1 220px;
}
```

三个值可以理解为：

```text
允许扩大  允许缩小  基础宽度 220px
```

#### `flex-shrink`

```css
.sidebar {
  flex-shrink: 0;
}
```

表示侧边栏空间不足时不要被 Flex 自动压缩。

## 六、响应式布局

响应式布局是指页面根据屏幕尺寸自动调整布局。

HTML 中通常需要：

```html
<meta name="viewport" content="width=device-width, initial-scale=1.0">
```

它让手机浏览器按照设备实际宽度计算页面。

媒体查询示例：

```css
@media (max-width: 700px) {
  .page-layout {
    flex-direction: column;
  }

  .sidebar {
    width: 100%;
  }
}
```

含义是：当屏幕宽度小于等于 700 像素时：

```text
电脑端：侧边栏 | 主内容
手机端：侧边栏
        主内容
```

常见辅助设置：

```css
.main-content {
  min-width: 0;
}
```

表示主内容允许在空间不足时缩小，避免内容撑破页面。
