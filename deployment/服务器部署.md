## 域名与证书

2026-10-13 已启用 `ee.yang2026.eu.cc`，Let's Encrypt 证书有效期至 2027-01-11。使用服务器现有 acme.sh 每日任务自动续期，续期后安装证书并调用 `reload-nginx.sh` 检查配置、重载 Nginx。

`deployment/nginx-domain-http.conf` 是首次签发证书时使用的 HTTP 配置，`deployment/nginx.conf` 是当前完整配置。重新部署域名时，先设置 A 记录和 HTTP 证书验证目录，签发并安装证书后再启用完整配置。

证书签发与安装命令：

```bash
/root/.acme.sh/acme.sh --issue --server letsencrypt \
  -d ee.yang2026.eu.cc --webroot /opt/ee-knowledge/acme --keylength ec-256
/root/.acme.sh/acme.sh --install-cert -d ee.yang2026.eu.cc --ecc \
  --key-file /www/server/panel/vhost/cert/ee.yang2026.eu.cc/privkey.pem \
  --fullchain-file /www/server/panel/vhost/cert/ee.yang2026.eu.cc/fullchain.pem \
  --reloadcmd /opt/ee-knowledge/reload-nginx.sh
```

原 Nginx 配置保存在 `/opt/ee-knowledge/ee-knowledge.before-domain.conf`，启用 HTTPS 前的配置保存在 `/opt/ee-knowledge/ee-knowledge.before-https.conf`。

## 日常操作

在服务器执行：

```bash
docker ps --filter name='^/ee-knowledge$'
docker logs --tail 100 ee-knowledge
docker restart ee-knowledge
curl --fail http://127.0.0.1:18083/api/health
```

修改 AI 配置后需要重建容器以重新加载 `--env-file`；仅执行 `docker restart` 不会读取新的环境文件。

## 更新项目

先在本机构建前端，并运行接口与检索检查：

```powershell
npm --prefix frontend run build
uv run python -X utf8 tests/test_api.py
uv run python -X utf8 tests/rag_eval.py
```

将 `app/`、`data/knowledge_base.json`、`frontend/dist/`、`deployment/`、`.dockerignore`、`pyproject.toml`、`uv.lock` 和 `README.md` 上传到服务器的新版本目录，例如 `/opt/ee-knowledge/releases/20261013-05`。不上传本机 `.venv`、`node_modules` 或个人报告；AI 密钥继续使用服务器上的独立配置文件。

然后在新版本目录构建镜像：

```bash
docker build -f deployment/Dockerfile -t ee-knowledge:20261013-05 .
```

确认镜像构建成功后，保留旧容器用于回退，再启动新版本：

```bash
docker stop ee-knowledge
docker rename ee-knowledge ee-knowledge-20261013-04
docker run -d --name ee-knowledge --restart unless-stopped \
  --read-only --cap-drop ALL --security-opt no-new-privileges \
  --tmpfs /tmp:rw,noexec,nosuid,size=64m --memory 512m \
  --env-file /opt/ee-knowledge/shared/.env \
  -p 127.0.0.1:18083:8000 ee-knowledge:20261013-05
```

等待日志出现 `Application startup complete` 后检查 `/api/health`，再更新版本链接：

```bash
ln -sfn /opt/ee-knowledge/releases/20261013-05 /opt/ee-knowledge/current
```

需要回退时，先停止新容器并给它改名，然后将旧容器恢复为 `ee-knowledge` 并启动，同时恢复 `current` 链接。旧镜像和旧版本目录保留。
